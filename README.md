# turnos-catalog-service

Servicio de catálogo del sistema distribuido de turnos. Mantiene una réplica local de
categorías, profesionales y horarios semanales, sincronizada con el servicio central de
la cátedra, y resuelve las búsquedas del catálogo.

Forma parte del sistema junto con
[turnos-appointments-service](https://github.com/Final-Programacion-II/turnos-appointments-service)
y [turnos-kmp-app](https://github.com/Final-Programacion-II/turnos-kmp-app).

Documentación en [`docs/`](docs/).
